# BRP
Code and data accompanying the paper 'Burst-related potentials as a temporal anchor for cognition' by Schuma, Landau, Diester, Anderson & Karvat, under revision in Communication Biology.\
To generate figures 2 and 3, download the functions and data into one folder, and enter that folder to the variable 'BRP_folder'. 
Requirements: 
- MATLAB R2020b or later 
- Signal Processing Toolbox
- Image Processing Toolbox
- Statistics and Machine Learning Toolbox
- Fieldtrip toolbox (freely available from https://www.fieldtriptoolbox.org/download/; tested on version 20241211).
